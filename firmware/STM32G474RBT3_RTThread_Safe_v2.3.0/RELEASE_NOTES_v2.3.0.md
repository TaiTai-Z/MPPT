# v2.3.0 发布说明（RT-Thread 版）

本版本仅修改并交付 RT-Thread Nano 工程。裸机工程未修改。

## 已整改

- 串口 TX 非阻塞整帧队列、RX 有界批量排空。
- 外部故障影子改为当前电平，修复清故障后旧值复活。
- I1/I2 各自校准并以有符号和重构输入电流。
- 持续扰动 P&O、样本有效性、滤波、软启动、Boost可达性和母线限幅切换。
- 逐周期2.0-A限流及2.5-A锁存OCP。
- PV UVLO、相失衡、卡零、建压/饱和超时、功率上限和样本陈旧保护。
- W25Q128 A/B校准存储及4槽关键故障持久化。
- 受全部安全门约束的两相A2/B1 180°输出后端和强HRTIM故障处理程序。

## 保留的安全阻断

- 功率输出编译门保持0；缺少MCU可读15-V PGOOD以及已测量的FLT/EEV极性、
  保持时间与HRTIM路由证据。
- 44 mV/A、PV/VBUS分压和 `gain_ppm` 已直接用于采样换算与保护，但它们不是
  控制器补偿增益。平均电流 PI 与外环稳定性仍需功率级模型和低压台架整定。
- 用户确认实装输出电容为450-V耐压，因此不按旧网表400-V标注降低现有400-V
  目标；415-V OVP继续保留，450 V不是允许工作目标。

## 证据

- v2.2.0：用户提供 ArmClang 6.24 Rebuild 0 Error/0 Warning。
- v2.3.0：静态契约与主机GCC语法检查；未执行ArmClang、烧录、示波器或实板运行。
