# 功率输出解锁前的硬件阻断项

以下项目不是软件宏可以替代的。全部关闭前，`BOARD_POWER_OUTPUT_ARMING_ENABLE`
必须保持 0，固件不得写 HRTIM `OENR`。

## 1. 逐周期故障源

2026-08-28 非同步功率板网表中 `FLT_1..FLT_6`、`EEV_1..EEV_2` 每个网络都
只有 U9 连接器端点，未连接过流比较器、驱动器故障输出或其他硬件源。因此：

- 当前100-kHz同步ADC软件OCP只能作为后备；它仍需ADC转换和CPU ISR，不能
  代替异步比较器到HRTIM FLT的逐周期硬件关断；
- 必须增加硬件比较器/驱动故障到至少一个 HRTIM FLT 输入；
- 必须记录极性、滤波、锁存、阈值、上电默认态，并用示波器验证从故障到
  PA9/PA10 关闭的传播时间；
- 只有随后才能实现并验收 HRTIM `FLTINR/FLTxR` 配置。

## 2. 15 V 可观测性

PA5 只控制 MP9486 DIM/EN。当前没有 MCU 可读的 15 V、PGOOD 或驱动 UVLO
状态；GPIO ODR 回读不能证明电源已经建立。应增加分压 ADC 或数字 PGOOD，
并给出启动超时、UVLO 和掉电阈值。

## 3. PV OVP 阈值

网表可确认 PC0 是 PV 测量通道，但没有给出系统允许的 PV 绝对上限。代码将
`BOARD_PV_OVP_LIMIT_MV` 保持 0，并把状态报告为 `LIMIT_REQUIRED`，不会猜测
80 V、90 V 或其他阈值。需要根据组件额定值、PV 串配置、容差和实测校准给出
正式值后再启用。

## 4. 低能量台架验收

补齐以上硬件后仍需按以下顺序验收：

1. 不连接高压母线，确认 PA9=Timer A2、PA10=Timer B1，U11 后仍为 CHE2/CHF1。
2. 确认 PA2 高时两路 UCC27511 都被禁止，PC14 高时 U11 第三组输出高阻。
3. 先以限流低压电源验证 100 kHz、占空比范围、相位和关断顺序。
4. 注入每一路硬件 FLT，确认无需 CPU/RTOS 参与即可关闭输出并保持锁存。
5. 验证 ADC 触发位置、2.824-us转换预算、ISR最坏时间和序列完整性；若后续
   引入DMA，其缓冲必须位于`0x20000000`普通SRAM而不是CCM。
6. 验证看门狗、HardFault、NRST 和调试器复位都回到相同安全态。

## 5. 器件记录

实物确认是 STM32G474RBT3，Keil 的 `STM32G474RBTx` 与 128 KiB Flash 算法
正确。应把原理图库中 `PARTTYPE/Device=STM32G474RET3` 改为 RBT3，避免后续
BOM、采购和固件目标再次分叉；这项 EDA 修订不应通过把固件改成 RETx 来掩盖。
